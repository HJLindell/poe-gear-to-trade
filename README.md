# Gear to Trade

Firefox extension: ctrl+click an item on a pathofexile.com character page to open a trade search with its mods filled in.

## Install (temporary)

1. Open `about:debugging#/runtime/this-firefox`.
2. Click "Load Temporary Add-on..." and pick `manifest.json`.
3. Reload the character page and ctrl+click an item.

Needs Firefox 128 or newer. Temporary add-ons are removed when Firefox closes.

## What it searches

- **Uniques:** name and base type, with every mod ticked. Foulborn uniques use the plain name plus the Foulborn filter.
- **Rares and magic items:** slot category (armour, jewellery) or exact base (everything else), plus:
  - resistances, life, mana and attributes as "total" pseudo stats
  - local defences as the item's final Armour / Evasion / Energy Shield value
  - fractured and crafted mods under their own category
  - every other mod as its own filter
- Minimum values are 90% of the item's roll (`MIN_PCT` in `content.js`).

A toast shows how many mods matched and lists the ones that did not.

## How it works

- `intercept.js` reads the item JSON the page itself loads from `/character-window/get-items`. The extension makes no requests of its own.
- `content.js` maps mod text to trade stat ids and opens `pathofexile.com/trade/search/<league>?q=<query>` in a new tab.
- `data/stats.js` is the bundled stat table, generated by `build.js`.

## Not covered

Influence, corruption, sockets and links, item level, gem level and quality, and PoE2 characters.
